# CC-2026.4

Registro de estudos do 4º semestre de Ciência da Computação.

## Disciplinas

### Programação de Software Básico em C
Ponteiros, alocação dinâmica de memória, controle de fluxo e manipulação de arquivos em C.

### Matemática Avançada
Cálculo diferencial e integral, matrizes, transformações lineares e aplicações numéricas.

### Análise de Dados
Coleta, tratamento estatístico, sumarização e visualização de conjuntos de dados.

### Modelagem de Sistemas em UML
Diagramas estruturais e comportamentais da UML voltados à análise e engenharia de software.

### Ciência de Dados em Python
Manipulação, análise exploratória e modelagem preditiva com ecossistema Python.
